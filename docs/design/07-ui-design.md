# 界面设计

## 屏幕路由状态机

游戏共 5 个全屏场景 + 1 个弹窗组件，由 Zustand store 的 `screen` 字段控制：

```
TitleScreen → GameScreen ⇄ CombatScreen → GameScreen
                  ↓                              ↓
            RelationGraph                   EndingScreen
              (覆盖)                       (不可返回)
```

| 屏幕 | 触发进入 | 可返回 |
|------|----------|--------|
| TitleScreen | 游戏初始化 / 重新开始 | — |
| GameScreen | 开始游戏后默认屏幕 | ✓ |
| CombatScreen | 触发战斗（剧情/遭遇/NPC/终极） | ✓（战斗结束后） |
| RelationGraph | 右栏"关系图→"点击 | ✓ |
| EndingScreen | 第 30 天结束判定结局 | ✗（仅"重新开始"） |
| NpcDetailModal | 右栏点击 NPC | ✓ |

## GameScreen — 主游戏界面

### 布局（桌面端 ≥1024px：双栏）

```
┌─────────────────────────────────────────────────────────┐
│  TimelineBar：第 X 天 | 卯 午 酉 子 | ♥ 85 | ⚡ 60    │
├───────────────────────────────────┬─────────────────────┤
│                                   │  CharSheet          │
│  EventArea（滚动）                │  生命/气力/攻/防    │
│  ├ 场景描写（斜体、淡墨）        ├─────────────────────┤
│  ├ 对话序列                      │  WeaponSlot         │
│  │  ├ 说话人（门派色）            │  4 招武学（可切换） │
│  │  └ 台词（逐字打印）           ├─────────────────────┤
│  ├ 分割线（墨迹渐变）            │  FavorDisplay       │
│  └ 好感度变化预览条              │  12 NPC 好感度简览  │
│                                   │  （可展开全部）     │
├───────────────────────────────────┤  "关系图→" 链接    │
│  ActionPanel                      ├─────────────────────┤
│  标题：选择你的行动               │  FactionReputation  │
│  ├ 选项 A（朱砂红·主选项）       │  已接触门派声望值   │
│  ├ 选项 B（灰纸色·次选项）       │                     │
│  └ 选项 C（灰纸色·可选）         │                     │
└───────────────────────────────────┴─────────────────────┘
```

### GameScreen 组件拆解

| 组件 | 职责 | 数据来源 |
|------|------|----------|
| `TimelineBar` | 天数/时辰/生命/气力 | store.state.currentDay, timeslot, health, qi |
| `EventArea` | 场景描述 + 对话滚动 | 当前触发的 Event 对象 |
| `DialogueBox` | 单条对话（说话人 + 台词 + 逐字打印） | Event.dialogues[i] |
| `ActionPanel` | 2-4 个可选行动 | Event.choices（经 conditions 过滤） |
| `CharSheet` | 角色属性网格 | store.state（health/qi/attack/defense） |
| `WeaponSlot` | 4 个武学槽位 | store.state.equippedSkills |
| `FavorDisplay` | NPC 好感度进度条 | store.state.npcFavors |
| `FactionReputation` | 门派声望列表 | store.state.factionReputation |

### 移动端降级（<768px：单栏）

```

┌─────────────────┐
```

## TitleScreen — 主标题

**视觉**：墨黑背景，朱砂红标题字，水墨动态背景（CSS gradient 动画）

**元素**：
- 游戏标题「一念江湖」（宋体 48px，鎏金色）
- 副标题「一念成佛，一念成魔。」（宋体 18px，淡墨）
- 按钮：「开始游戏」（印章式朱砂红按钮）
- 按钮：「结局回顾」（仅在已触发 ≥1 个结局时显示）

## CombatScreen — 战斗界面

### 回合制战斗布局

```
┌─────────────────────────────────────────────────────────┐
│  对手信息栏：敌人名称 | ♥ 120/120 | 属性图标            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│             战斗动画区域（全屏/半屏）                    │
│             招式名 + 伤害数字 + 墨迹特效                 │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  玩家信息栏：无名少侠 | ♥ 85/100 | ⚡ 60/100 | 攻/防   │
├─────────────────────────────────────────────────────────┤
│  战斗日志（最近 3 行滚动）                              │
├─────────────────────────────────────────────────────────┤
│  行动选项：                                             │
│  [ 太虚十三剑·攻 30⚡ ] [ 剑气如虹·防 20⚡ ]           │
│  [ 防御 -50%受伤 ]      [ 逃跑（部分战斗不可逃） ]     │
└─────────────────────────────────────────────────────────┘
```

**战斗类型差异**：

| 类型 | 展示模式 | 标题 |
|------|----------|------|
| 剧情战 | 半屏（overlay，不中断时间流） | "苏青衡 向你发起挑战" |
| 遭遇战 | 全屏（独立场景） | "山道贼人" |
| NPC 挑战 | 半屏 | "厉无双：小子，接我一招！" |
| 终极战 | 全屏 | 第 30 天特殊背景 |

## RelationGraph — 关系图

**实现**：d3-force 力导向图 + React SVG 渲染

```
┌─────────────────────────────────────────────────────────┐
│  ← 返回游戏                                              │
│                                                         │
│     ○ 苏青衡          ○ 沈听雨                          │
│        \              /    \                             │
│    [旧情缘]     [闺蜜]    [养母女]                       │
│          \        /         /                            │
│           ○──────○──── 陆小满                            │
│           玩家                                           │
│          / |  \                                         │
│     [师徒] [旧友] ...                                    │
│                                                         │
│  图例：── 金色正面关系  ── 暗红负面  ── 灰色中性         │
└─────────────────────────────────────────────────────────┘
```

**交互**：
- 节点大小：与玩家好感度总和成正比
- 节点颜色：对应门派色 / 散人灰色
- 点击节点：弹出 NpcDetailModal
- 未发现的 NPC 节点：半透明 + 标签"???"

## EndingScreen — 结局展示

**动画流程**：
1. 水墨渐隐（2000ms）— 上一屏画面淡出
2. 场景背景淡入（对应结局的区域背景）
3. 诗意结语逐字打印（居中，宋体斜体）
4. 结局名称 + 结局画面描述
5. 按钮：「查看结局收集」/「重新开始」

## UI 组件速查

| 组件 | 关键交互 | 动效 |
|------|----------|------|
| `DialogueBox` | 逐字打印（50ms/字），点击跳过 | 文字渐显 |
| `ActionPanel` | 印章式按钮 hover 旋转 | hover 微旋转 1° |
| `FavorDisplay` | 数值滚动 + 闪烁 | 300ms 过渡 |
| `CombatUI` | 招式选择 → 动画播放 → 伤害数字 | 500ms 墨迹飞溅 |
| `NpcDetailModal` | 打开淡入 + 点击背景关闭 | 200ms 淡入 |
| `RelationGraph` | 拖拽节点、点击查看详情 | 力导向实时计算 |
